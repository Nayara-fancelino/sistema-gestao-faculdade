# Sistema de Gestão de Faculdade

Projeto desenvolvido em grupo durante o Bootcamp Back-End .NET 2026.2 da WoMakersCode.

## Sobre o projeto

Sistema de Gestão de Faculdade desenvolvido em C# utilizando Programação Orientada a Objetos.

A aplicação será executada pelo Console e permitirá o gerenciamento de cursos, professores, alunos, disciplinas, matrículas, boletins acadêmicos e notificações.

## Tecnologias utilizadas

- C#
- .NET 10
- Programação Orientada a Objetos
